# Actividad del proyecto

## 0. Introducción

La aplicación es un portal para consultar dispositivos tecnológicos. Permite explorar productos, aplicar filtros, visualizar sus características, consultar imágenes, revisar calificaciones y publicar comentarios.

## 1. Instalación y ejecución normal

La guía para instalar Node.js directamente, configurar Angular CLI de forma global y ejecutar el proyecto se encuentra en [config/normal.md](./config/normal.md).

## 2. Instalación y ejecución por versión

La guía para administrar versiones de Node.js con NVM, configurar variables de entorno y ejecutar Angular sin instalación global se encuentra en [config/version.md](./config/version.md).

## 4. Lenguaje de programación

El frontend está desarrollado principalmente con **TypeScript**, lenguaje que añade tipado estático a JavaScript y facilita la construcción y mantenimiento de aplicaciones Angular.

| Lenguaje | Versión configurada |
| --- | --- |
| TypeScript | 6.0.2 |

## 5. Tecnología utilizada

La aplicación está construida con **Angular**, un framework para crear interfaces web modernas, organizadas por componentes y orientadas a aplicaciones de una sola página.

| Tecnología | Tipo | Versión configurada |
| --- | --- | --- |
| Angular | Framework frontend | 22.1.x |

## 6. Dependencias configuradas

| Dependencia | Uso principal | Versión configurada |
| --- | --- | --- |
| Bootstrap | Estilos responsivos, componentes visuales y diseño de la interfaz. | 5.3.8 |
| DataTables | Tablas con paginación, búsqueda, ordenamiento y visualización de datos. | 3.0.2 (`datatables.net-bs5`) |
| SweetAlert | Alertas, confirmaciones y mensajes interactivos. | 11.26.25 |
